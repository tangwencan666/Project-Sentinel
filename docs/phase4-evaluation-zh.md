## 失败与限制

重试风暴是推理失败：模型看到约 4.9 倍 payment 调用，却把 payment 快速 503 视为源头，推测未读取的 Redis 故障 key；真实目标是 order 五次无退避重试。根因和服务都保留为错误。

冻结 Critic 交接存在遗漏；原记录举一例，后续独立审计确认八场均遗漏。可读 generic fault helper 也暴露实验实现线索。当前必需引用保护不等于新的 8/8 验证。

V4 两场受 Docker 重启后无关 consumer 失败混杂，保留原分且不入 Pareto；其余六场子集不能替换八场。V2/V3 有首个有效连接池试验选择，V4.1 又改变业务抽取与可读源码，不是单变量压缩对照。八场单次、同模型评分不支持生产泛化或统计显著性结论。
