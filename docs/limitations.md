# 当前限制

1. **样本只有八个受控场景。**7/8 (87.5%) 是这次实验计数，不是生产准确率、统计稳定性或泛化保证。
2. **不是企业真实生产流量。**服务、种子数据、压测与故障均由项目控制；真实执行不等于真实企业使用。
3. **模型覆盖有限。**实际云实验以 deepseek-chat 为主，没有多模型横评；同模型 Investigator/Critic 的错误可能相关。
4. **成本偏高。**V4.1 八场工作流 1,461,870 tokens，主要为输入；未配置价格时不报告虚构金额。
5. **Critic 不完整。**八场均为 PARTIALLY_VERIFIED，并发现根因引用证据交接遗漏；不能把模型复核当作独立事实认证。
6. **实验盲性有限。**显式真值接口被隔离，但 generic fault helper 可见；规则基线编码领域模式。没有完全排除实验线索。
7. **错误结果未解决。**重试风暴仍归因错误，未用特殊规则或反复跑分覆盖。
8. **通用 Patch 能力有限。**只支持四类受限业务函数；合同与八输入 replay 不等于完整业务回归，不能修任意仓库。
9. **Sandbox 不等于生产发布。**受限进程与专用依赖命名空间仍共享内核；演示候选 HIGH risk、NOT DEPLOYED。
10. **Runtime 与 Live 安全尚不成熟。**无完整多租户鉴权、执行租约、发布审批和生产 SLO；远端响应持久化前失败可能重复计费。
11. **历史回放有边界。**204 条事件来自同一 Run；精确注入时间缺失，只有首次观察时间。回放不重新执行工具。
12. **离线需要预备环境。**镜像构建好后可无模型、无外部网络运行；源码 ZIP 不包含镜像，首次依赖下载通常要网络。没有部署公网或声称安全认证。
